# Simple-traffic-management-system
This is a simple traffic management system using Python done for software development project.
This gets inputs from csv files. And then it is creating graph. Graph contains two axis. Y axis as number of vehicles and x axis as hour in 24 hour format.
After that details are written to text file. Furthermore this is working on 3 specific dates [16/06/2024, 21/06/2024, 15/06/2024]. Because details are only provided for these 3 days.
Mainly Python s used for this. And the tkinter is used for GUI part.
